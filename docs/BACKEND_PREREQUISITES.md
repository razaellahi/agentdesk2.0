# Backend prerequisites

Agent Desk 2.0 replaces three front ends with one login and one origin. These backend changes or confirmations are needed. Each item names its owner, how the front end behaves until it is done, and how to verify it.

| #   | Item                                                                                                                                                                                                                                                                                                                                               | Owner                             | Front-end behaviour until done                                          | How to verify                                                                |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------- | ----------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| 1   | **VRS accepts the agent-manager Keycloak token**: same realm, audience and `azp` accepted. Realm roles `agent`, `supervisor`, `admin`, `download`, `export`, `viewtag` and `evaluatetag` are present in `realm_access.roles`.                                                                                                                      | VRS backend                       | Recordings calls get 401, which ends the session.                       | Log in through Agent Desk 2.0 and call `GET /vrs/recordings` with the token. |
| 1b  | VRS **LOGIN audit event**: today it is written by `POST /vrs/login`, which Agent Desk 2.0 no longer calls. Add a hook or endpoint, for example `POST /vrs/audit-logs {action:"LOGIN"}` accepted from the client.                                                                                                                                   | VRS backend                       | The front end posts `LOGIN` after login once the endpoint exists.       | Check audit-log screen entries.                                              |
| 2   | **agent-manager `/agent/login` serves non-agent users** (admin-only, VRS-only). The response `permittedResources` includes `agent-desk-setting` with `view`/`manage`. Logging in must not make the user an active agent.                                                                                                                           | agent-manager                     | Admin-only users may be rejected at login.                              | Log in as an admin user with no agent role.                                  |
| 3   | **unified-admin enforces auth** on `PUT /agent-desk-settings` and `POST`/`PUT /locale-setting`. It must verify the JWT and require the `manage` scope. `GET` may stay public (it is needed before login).                                                                                                                                          | unified-admin                     | Works; the UI hides Save without `manage`, but the API is open.         | `PUT` without a token returns 401.                                           |
| 4   | **Real reporting endpoints** for queued and active chats (UA `http.service` still points `getQueuedChats`, `getActiveChatsWithAgents` and `getActiveChatsWithBots` at a Postman mock), plus a **re-queue API**.                                                                                                                                    | realtime-reports / routing-engine | The supervisor Queues screen shows data without re-queue.               | —                                                                            |
| 5   | **VRS paging contract**: `master` returns `{data,total}` with `offset`/`pageSize`, but the PTCL tag branch reverts to a plain array. Agree on `{data,total}`.                                                                                                                                                                                      | VRS backend                       | The client accepts both shapes and pages client-side for arrays.        | —                                                                            |
| 6   | **File-engine reference translations** for `application=agent-desk` must include the new Agent Desk 2.0 namespaces (`nav`, `shell`, `auth`, `errors`, `preferences`, and later `recordings`, `admin-settings`, `board`), otherwise the Translations screen's validation flags them as extra keys. Generate the payload from `public/i18n/en.json`. | file-engine                       | The bundled English fallback is shown for new keys.                     | Translations screen shows no validation errors.                              |
| 7   | **Ingress** serves `/agent-desk/` on the same FQDN as the services and `/vrs`. `FRAME_ANCESTORS` lists the Finesse and CRM hosts that embed the desk.                                                                                                                                                                                              | DevOps                            | —                                                                       | Load `https://<tenant>/agent-desk/` and embed it in Finesse.                 |
| 8   | **Cisco and CX secrets** (`ctiParam`, `ctiParam2`, `EXT_STATIC`) are AES-decrypted in the browser with a hard-coded passphrase (UA `appConfig.service.ts`). Provide them server-side to the authenticated agent instead.                                                                                                                           | unified-admin / agent-manager     | The passphrase is isolated in one module of `core/telephony` (Phase 5). | No passphrase in the bundle.                                                 |
